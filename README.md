# MedYouMore+

## Overview
MedYouMore+ is a browser extension designed to extend the functionality of the MedUMore platform.

## Features
- Caption extraction
- Screenshot video and export to PDF

## Get started
This extension is written for Google Chrome. Please follow the https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked to load unpacked extension in developer mode.
